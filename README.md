Варіант 17. Баланс енергії / витривалості персонажа.

Система моделює механіку управління енергією (Stamina) персонажа в мобільній грі. Гравець використовує енергію для входу в рейди. Енергія поступово відновлюється з часом або миттєво поповнюється за допомогою зілля. Під час підвищення рівня персонажа збільшується його максимальний запас енергії.
Система дозволяє відстежувати поточний стан персонажа, обробляти ігрові події та запобігати виконанню недозволених операцій.
